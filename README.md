# metroscope

**서울 지하철 관제실 화면, 근데 예쁘고 소리도 나는.**

네이버 지도가 "내가 어떻게 가지?"에 답한다면, metroscope는 **"지금 지하철 전체가 어떤 상태지?"**에 답합니다.

- 🫀 **살아있는 노선도**: 2호선 순환선을 원으로 그리고, 열차가 점처럼 흘러갑니다 (바깥 외선, 안쪽 내선)
- 📏 **열차 간격 시각화**: 열차 사이 구간을 간격에 따라 색칠합니다. 몰림(청록), 정상(초록), 넓음(주황), 공백(빨강)
- 🎵 **소리 모드**: 열차가 역에 도착할 때마다 음이 울립니다. 출근길엔 교향곡, 새벽엔 고요함

## 실행

```bash
npm install
npm run dev
# http://localhost:3000
```

API 키 없이도 **시뮬레이션 모드**로 바로 돌아갑니다.

### 실시간 데이터 연결

1. [서울 열린데이터광장](https://data.seoul.go.kr)에서 **실시간 지하철 인증키**를 발급받습니다
2. `.env.example`을 `.env`로 복사하고 `SEOUL_API_KEY`를 채웁니다
3. 기본 `POLL_MS=75000`: 일일 한도 1,000회 기준, 운행 시간(05:30~01:00)에만 폴링해 하루 약 936회를 씁니다. 새벽엔 자동으로 쉽니다. 업데이트 사이엔 브라우저가 열차를 진행 방향으로 살짝씩 움직여 부드럽게 보이게 합니다.
4. 서버가 한 번 받아 모든 접속자에게 SSE로 뿌리므로, 접속자가 늘어도 API 호출은 늘지 않습니다

## 구조

```
server/
  index.ts         Express + SSE 브로드캐스트
  lines.ts         노선 정의 (역 순서, 색상)
  feeds/seoul.ts   서울시 realtimePosition API → 열차 위치
  feeds/mock.ts    API 키 없을 때 쓰는 시뮬레이터
web/
  index.html, style.css, app.js   빌드 없는 순수 JS 프론트엔드 (SVG + Web Audio)
```

## 알려진 한계

- API가 **역 단위**(진입/도착/출발/전역출발)로만 위치를 줘서, 역 사이 위치는 추정값입니다
- 성수지선·신정지선은 아직 표시하지 않습니다
